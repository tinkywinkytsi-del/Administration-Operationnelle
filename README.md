# Administration-Operationnelle

Module commun des conversations du projet **TSI** — agents, skills, commandes et
contexte partagé.

Le point d'entrée pour un agent est [`CLAUDE.md`](CLAUDE.md) (identique à
`AGENTS.md`). Commence par là.

## Installation dans une conversation TSI

```bash
git clone https://github.com/<compte>/Administration-Operationnelle.git
```

Puis, depuis le projet TSI, installer ce repo comme plugin Claude Code, ou
simplement ouvrir la conversation dans ce dossier.

## Règle mère

Les conversations TSI utilisent **ce module**, et lui seul.
Détail et justification dans [`CLAUDE.md`](CLAUDE.md).
